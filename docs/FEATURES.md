# PinPin 完整功能規格（給網站撰寫用）


這份文件描述 PinPin **實際做得到的事**，寫網站時以這裡為準；沒寫在這裡的功能請不要寫上網站。
「⚠ 尚未實測」的項目功能已完成，但作者還沒在真實桌面上完整操作過，網站可以介紹，避免寫成保證的效能數字。

## 1. 產品一句話

- 中：溫暖可愛的 Windows 桌面便利貼——圖釘、紙膠帶、貼紙、手寫、透明標語、番茄鐘，平常幾乎不耗電。
- 英：Cozy sticky notes for your Windows desktop — pins, washi tape, stickers, handwriting, transparent slogans and pomodoro timers, with almost zero idle CPU.

**定位**：取代 Windows 內建的「便利貼」，給喜歡手帳、文具、桌面佈置的人。重點是「好看、手感好、很省電」，不是雲端協作工具。

**目標使用者**：學生、上班族、手帳愛好者、需要在桌面放提醒或座右銘的人、用番茄鐘工作法的人。

**不是什麼**（網站不要暗示）：沒有雲端同步、沒有帳號、沒有手機版、沒有多人協作、不是 Mac／Linux 程式。換電腦靠「匯出／匯入 JSON」手動同步。

## 4. 詳細規格

### 4.1 便利貼

- **新增**：系統匣圖示左鍵、系統匣選單、桌面右鍵「新增便利貼」、便利貼上的 ＋ 按鈕、Ctrl+N、從剪貼簿新增（文字或圖片）
- **紙的顏色**：17 種
  - 經典 8 色：鵝黃、蜜桃粉、天空藍、薄荷綠、橘子、薰衣草、白、牛皮紙
  - 莫蘭迪 8 色：乾燥玫瑰、霧藍、鼠尾草、燕麥奶、灰紫、奶茶、芥末黃、暖灰
  - 特別：透明（見 4.6）
- **紙質**：7 種——便利貼（上緣黏膠、右下角微翹）、平滑、方格、橫線、點陣、和紙纖維、牛皮紙纖維
- 新便利貼沿用上次選的顏色、紙質、釘法（透明紙不會變成預設）
- **編輯**：連點兩下或 F2／Enter，直接在紙上打字；Esc 或點外面收起；Ctrl+Enter 也可收起
- **大小**：右下角拖曳改紙張大小
- **捲動**：內容超出時滾輪捲動，上下緣淡出
- **陰影**：貼著時小而淡，拖起來時變大變散（像拿起一張紙）
- **出現動畫**：新便利貼滑下、淡入，圖釘再一個個「釘」上去
- **空白便利貼不會自動刪除**（作者刻意的設計）
- 滑過時右上角出現按鈕：刪除、選單、上鎖（解鎖中）、新增、手寫；右下角 A−／A+ 調字的大小

### 4.2 劃掉待辦

- 每一行左邊有圓圈，點一下用**紅筆**劃掉（有手寫筆跡的抖動和劃線動畫），再點一下取消
- 劃線**永遠是紅色**
- 右鍵：全部劃掉、全部取消、清掉劃掉的行
- 支援由右到左的文字（阿拉伯文、希伯來文的行從右邊劃過去）

### 4.4 自製貼紙

- 在貼紙小舖建立**自己的群組**（「＋ 新群組」），雙擊改名，右鍵左移／右移／刪除
- 加入方式（三選一）：
  1. 把圖片檔拖進小舖視窗
  2. Ctrl+V 或點「**貼上剪貼簿的圖片**」卡片（截圖後直接貼）
  3. 點「＋ 加入圖片」挑檔案（可多選）
- **自動處理**：
  - 去背：依圖片四邊的顏色判斷背景（不用 AI、不連網）；截圖、白底、單色底效果最好
  - 背景很花（例如照片）就不去背，整張做成圓角照片貼紙
  - 本來就是透明 PNG 的直接用它的透明度
  - 加一圈**圓弧白邊**（凹進去的地方也會被填成平滑的弧線，像真的割好的貼紙）
  - **保留原圖尺寸**（最長邊最多 4096px，不放大、不縮小），改用 **JPEG XR 品質 80%** 存檔（保留透明，檔案約是 PNG 的 1/4）；貼上便利貼時顯示大小約和內建貼紙一樣
- 內建貼紙也能右鍵「收進群組」，或拖到群組分頁上
- 刪除群組時會先確認；已經貼在便利貼上的自製貼紙不受影響
- 匯出／匯入會一起帶著群組和自製貼紙

### 4.5 手寫

- 進入方式：便利貼右上角筆的按鈕、右鍵「手寫」、系統匣「新增手寫便利貼」
- 紙張下方出現**工具列**：
  - 4 種筆：**鋼筆**（頭尾稍細）、**螢光筆**（半透明、粗）、**粉筆**（顆粒、毛邊）、**蠟筆**（蠟紋、紙紋露白）——按鈕上直接畫出該筆的筆觸當圖示
  - 8 種顏色：墨黑、白、紅、橘、黃、綠、藍、粉紅
  - 3 種粗細
  - 橡皮擦（碰到的整筆拿掉）、復原、完成
- 快捷鍵：Esc／Enter 結束，Ctrl+Z 復原，E 切換橡皮擦
- 筆跡在字上面、圖釘下面；筆的質感跟著紙走，移動便利貼不會閃
- 右鍵「清除手寫」
- 存檔前自動簡化筆跡點數，檔案很小

### 4.6 透明紙（桌面標語）

- 紙的顏色選「透明」，或系統匣「新增透明手寫標語」
- 沒有紙、沒有陰影，**只看得到字和筆跡**，像直接寫在桌布上
- 滑鼠移上去才出現淡淡的虛線框和按鈕，方便移動、編輯
- 打的字和手寫都可以；搭配大字級、粗體、亮色字，適合座右銘、目標、今日重點
- 可以「釘在桌面」放在所有視窗下面

### 4.7 文字樣式

- **顏色**：自動（依紙色）、10 色（墨黑、咖啡、紅、橘、黃、綠、藍、紫、粉紅、白）、自訂顏色（系統調色盤）
- **字型**：列出這台電腦有裝的常用字型（微軟正黑體、標楷體、新細明體、微软雅黑、黑体、游ゴシック、メイリオ、맑은 고딕、Segoe UI、Segoe Print、Segoe Script、Ink Free、Comic Sans MS、Impact、Arial Black、Georgia），另外可以從系統字型對話框選**任何字型**
- **粗體**
- **大小**：小、標準、大、特大、標語、超大標語、巨大（最大 **6 倍**）；A−／A+、Ctrl+滾輪每次 ±12%；字放不下時紙會自動長高
- **兩層設定**：
  - 通用：系統匣「文字預設樣式」——沒有自己設定的便利貼全部跟著變
  - 單張：便利貼右鍵「文字樣式（這張）」——只改這一張，可隨時「跟著預設」或「全部改回預設」
  - 也可以「把這張的樣式設成預設」

### 4.8 圖片便利貼（拍立得）

- 拖圖檔到便利貼上，或在便利貼上 Ctrl+V 貼上圖片，變成**拍立得**樣式（白框、下方圖說）
- 圖說用手寫風字型；連點兩下編輯圖說
- 右鍵：複製圖片、另存圖片；轉了角度的多一個「擺正」
- **轉角度**（和貼紙一致）：滑鼠在拍立得上**滾輪轉角度**（一格 6°）、**Shift+滾輪放大縮小**（繞中心）；或拖左上角的轉角度鈕（滑過才出現），拖的時候按 Shift 一次 15°、接近 0° 自動吸正；點一下轉角度鈕＝擺正
  - 整張一起轉：膠帶、貼紙、陰影、滑過的按鈕都跟著轉；陰影永遠往正下方
  - 連點兩下編輯圖說、手寫時會暫時擺正（編輯框不能斜），結束後轉回去
  - 轉了角度的拍立得**不吸附**對齊（斜的紙沒有可以對齊的邊，用外框對齊會留下奇怪的空隙），別張也不會吸到它
- 支援 PNG、JPG、GIF、BMP、WebP、TIFF、ICO、HEIC（看系統有沒有對應的解碼器）

### 4.9 番茄鐘

- 新增：系統匣「新增番茄鐘」、**桌面右鍵「新增番茄鐘」**
- **6 種樣式**（右鍵「樣式」切換）：
  1. 番茄：紅番茄、進度圈、秒點；休息時變綠番茄
  2. 沙漏：木框玻璃沙漏，沙子會往下流
  3. LED 數字錶：七段顯示器發光數字、冒號一秒閃一次、下方一排小燈表示剩多少
  4. 鬧鐘：雙鈴鬧鐘，錶面有刻度、剩餘時間扇形、秒針
  5. 抱時鐘的貓
  6. 抱時鐘的柴犬
- **整個番茄鐘不會晃動，只有倒數的地方會變**（作者要求）
- 操作：點一下開始／暫停（空白鍵），R 這一段重來；停著時滾輪調分鐘（Shift 一次 5 分，1～180 分）
- 右鍵：開始／暫停、重來、直接跳到休息／專注、專注時間（15、20、25、30、45、50、60 分）、休息時間（3、5、10、15、20 分）、樣式、時間到的聲音、釘在桌面／最上層、完成的番茄歸零、刪除
- **專注、休息自動輪替**；完成的番茄數用小紅點顯示
- **時間到**：播放聲音＋右下角提示＋原地閃一下
- **聲音**（選的時候會試聽）：內建「叮咚」、內建「鈴鈴鈴」、Windows 內建鬧鐘音效 1～10（有幾個列幾個）、自訂 .wav 檔、不出聲
- 省電：暫停時完全不跑計時器；番茄、LED、鬧鐘、貓狗每秒醒一次（對齊秒數、可被系統合併喚醒）；沙漏跑的時候每 0.2 秒畫一次
- 跑的時候只記「幾點結束」：關掉程式、重開機都接得上；如果關著的時候早就到了，會安靜地切到下一段，不補響

### 4.10 密碼便利貼

- 每張便利貼可以設**不同的密碼**（右鍵「密碼」→ 設定，輸入兩次）
- 加密：PBKDF2-SHA256（20 萬次）推導金鑰 + AES-256-GCM，用 Windows 內建的加密 API
- 鎖著時顯示一份**普通的偽裝待辦清單**（例如「超市：雞蛋、牛奶、吐司」），不會讓人看出這張有密碼
- 解鎖時文字先**亂碼**一陣再變回真正內容；上鎖時反過來；密碼錯會左右搖
- 可以換一份偽裝內容、移除密碼；Ctrl+L 上鎖；關掉或重開會自動鎖回
- 密碼和金鑰只在記憶體裡，存檔和匯出檔裡都看不到原文
- 偽裝內容依介面語言（各語言有 8 份）

### 4.11 星號記事本（搭配 Vibotype）

- 搭配作者的另一個工具 Vibotype：在任何程式選取文字、按 ★，收進同一本「星號記事本」，記下時間和來源程式
- 單獨使用 PinPin 時也可以從系統匣打開／收起星號記事本
- 其他程式可以透過 WM_COPYDATA 送指令新增便利貼或加星號（給開發者，網站可略）

### 4.12 擺放

- **磁吸**：靠近別張便利貼或螢幕邊緣 7px 內會輕輕吸住對齊，並排間距 10px；按住 Alt 拖曳不吸
- **方向鍵**微調 1px（Shift 10px）
- **釘在桌面**：放在所有視窗下面
- **永遠在最上層**
- 拖到沒有螢幕的位置（例如拔掉外接螢幕）下次開啟會自動搬回主螢幕

### 4.13 系統匣、桌面右鍵、開機

- 系統匣左鍵：新增便利貼；右鍵選單：新增、從剪貼簿新增、新增手寫、新增透明標語、新增番茄鐘、星號記事本、貼紙小舖、暫時收起全部、復原刪除、匯出、匯入、文字預設樣式、語言、桌面右鍵選單開關、開機啟動開關、開啟資料夾、結束
- 桌面右鍵：「新增便利貼」「新增番茄鐘」（Windows 11 在「顯示更多選項」裡）；和開機啟動一樣預設關閉，在系統匣打開
- 開機自動啟動（可關）
- 只會有一個執行中的 PinPin；再開一次等於叫它新增一張

### 4.14 匯出／匯入、復原

- 匯出成一個 JSON：全部便利貼、圖片、手寫、自製貼紙和群組；加密的內容仍然加密
- 匯入：同一張用匯入檔的版本，其他加進來；群組合併
- 刪除的便利貼進回收（最多留 20 張），系統匣「復原刪掉的便利貼」
- 第一次啟動會自動從舊版（Vibotype 內建的便利貼）搬資料

### 4.15 多語系

- 內建：English、繁體中文、简体中文、日本語、한국어、العربية
- 阿拉伯文：選單、貼紙小舖整個左右鏡像；便利貼內容**每一行自動判斷方向**（中英混阿拉伯文也正確）
- **自訂語言**：語言檔是平的 JSON；系統匣「語言 → 開啟自訂語言檔資料夾」，複製英文範本、翻譯右邊的字，不用重新編譯就出現在選單；沒翻到的字自動用英文；同代碼可只覆蓋幾個字

### 4.16 省電設計（網站可做一區）

- 平常**沒有任何計時器在跑**；只有內容或狀態改變時畫一次
- 動畫（出現、釘上、劃線、亂碼）播完就停
- 拖曳時只在滑鼠動的時候重畫
- 每張便利貼一次畫好交給系統合成（分層視窗），系統只留結果，畫完立刻釋放點陣圖
- 素材第一次用到才解碼；貼紙小舖關掉就釋放全部縮圖
- 番茄鐘見 4.9

## 7. 網站建議結構

1. 首屏：一句話＋下載按鈕＋產品截圖（便利貼在桌布上）
2. 宣傳影片
3. 功能分區（依第 3 節順序，每區一張截圖＋2–3 句＋重點條列）
4. 小細節卡片（磁吸、星號記事本、匯出、復原、桌面右鍵、多語系）
5. 省電（0% 閒置 CPU、約 15 MB、11 MB 單檔、完全本機）
6. 多語系＋自訂語言檔示範
7. 下載＋系統需求＋授權
8. 頁尾：原始碼、授權

網站本身也要多語系（至少與程式相同的 6 種，阿拉伯文要由右到左），宣傳影片預設英文。

## 線上更新

- 系統匣「更新」子選單：檢查更新、自動檢查更新（預設開）、接收推送（新貼紙、廣告、重要更新，預設開）
- 自動檢查：啟動 1 分鐘後、打開貼紙小舖時（超過一天才查）；有新版只在系統匣選單出現「⬆ 更新到 vX」，不跳提示
- 手動檢查才會跳出結果提示
- 重要更新：自動下載，下次啟動時套用（可以關掉）
- 線上貼紙包會出現在小舖，可以加進現有分類或新增分類；線上廣告會取代內建的三則
- 詳細流程與 feed 格式：docs/UPDATES.md
