> **바탕화면의 작은 메모가 늘 곁에.**

Windows 바탕화면 메모 앱. 압정, 마스킹 테이프, 스티커를 마음대로 붙이고, 손글씨, 투명 슬로건, 뽀모도로 타이머까지. 평소에는 전력을 거의 쓰지 않습니다.

- `.exe` 하나(약 11 MB), 설치 필요 없음, Windows 10 / 11
- 대기 중 CPU 0%, 메모리 약 15 MB(대기 타이머가 전혀 없고 화면이 바뀔 때만 다시 그림)
- 6개 언어: English, 繁體中文, 简体中文, 日本語, 한국어, العربية(오른쪽에서 왼쪽)
- 오픈 소스(MIT), 데이터는 내 컴퓨터에만 저장

## 기능

- **메모**: Windows를 켜면 바탕화면에 다시 나타납니다. 끌어서 옮기면 다른 메모나 화면 가장자리에 살짝 붙어 정렬됩니다(Alt를 누르고 끌면 붙지 않음, 방향키로 1px씩 미세 조정)
- **줄 긋기**: 줄에 마우스를 올리면 왼쪽에 동그라미가 나타나고, 클릭하면 빨간 펜으로 줄을 긋습니다(애니메이션)
- **압정, 클립, 마스킹 테이프, 스티커**: '스티커 가게'에서 메모나 바탕화면으로 끌어다 놓으세요. 스티커 146개(4배 해상도라 확대해도 선명)가 일상, 행운, 세계의 행운 부적, 화분, 춘련, 고양이와 강아지, 스쿠터, 대만 소품 8개 구역으로 나뉩니다. 클릭하면 핸들이 나타나 오른쪽 위로 회전, 오른쪽 아래로 크기를 조절합니다. 마스킹 테이프는 양 끝을 끌어 늘리고 방향을 바꿀 수 있습니다. 선택하지 않은 압정·클립·테이프를 끌면 메모 전체가 움직입니다
- **나만의 스티커**: 가게에 내 그룹을 만들고 이미지를 끌어다 놓거나 Ctrl+V, '＋'를 누르세요. 배경을 자동으로 지우고 둥근 흰 테두리를 붙입니다. 원본 크기(최대 4096px) 그대로 JPEG XR로 저장해 공간을 아낍니다. 기본 스티커도 그룹에 넣을 수 있습니다
- **맞춤 제작**: 가게의 마지막 카드가 웹사이트의 맞춤 제작 페이지로 연결됩니다(반려동물 스티커, 타이머 캐릭터, 테마 세트)
- **손글씨**: 펜, 형광펜, 분필, 크레용, 8가지 색, 3가지 굵기, 지우개, Ctrl+Z 되돌리기. **투명 종이**로 바탕화면에 떠 있는 손글씨 슬로건을 만들 수 있습니다
- **글자 스타일**: 색, 글꼴, 굵게, 크기(최대 6배). 트레이의 '기본 글자 스타일'은 전체, 오른쪽 클릭의 '글자 스타일(이 메모)'은 한 장만 바꿉니다
- **뽀모도로 타이머**: 토마토, 모래시계, LED 시계, 알람 시계, 시계를 안은 고양이, 시계를 안은 시바견. 클릭으로 시작/일시정지, 휠로 분 설정. 시간이 되면 울립니다(내장 알림음, Windows 알람 소리, 내 .wav 또는 무음). 멈춰 있을 때는 전력을 쓰지 않습니다
- **종이**: 클래식 8색 + 모란디 8색 + 투명. 포스트잇, 매끈한 종이, 모눈, 줄 노트, 도트, 화지, 크라프트 섬유
- **이미지**: 이미지 파일을 끌어다 놓거나 메모 위에서 Ctrl+V를 누르면 폴라로이드가 됩니다
- **비밀번호**: 메모마다 다른 비밀번호를 설정할 수 있습니다(PBKDF2 + AES-256-GCM). 평소에는 평범한 위장 할 일 목록이 보이고, 비밀번호를 입력하면 글자가 뒤섞였다가 원래 내용으로 돌아옵니다. 닫거나 다시 시작하면 자동으로 다시 잠깁니다
- **별표 노트**: Vibotype 선택 도구 모음과 함께 쓰면 어떤 프로그램에서든 글자를 선택하고 ★만 누르면 모아집니다
- **JSON 내보내기/가져오기**: 다른 컴퓨터로 옮기거나 직접 동기화(이미지, 손글씨, 나만의 스티커와 그룹까지 함께. 암호화된 내용은 암호화된 그대로)
- **바탕화면 오른쪽 클릭** '새 메모' '새 타이머'와 **Windows 시작 시 실행**, 모두 트레이 메뉴에서 끌 수 있습니다
- **온라인 업데이트**: 새 버전을 조용히 확인(트레이 메뉴에만 표시)하고, 중요한 업데이트는 자동으로 내려받아 다음 실행 때 적용합니다. 새 스티커 팩과 가게 배너도 온라인으로 받을 수 있으며 모두 끌 수 있습니다([docs/UPDATES.md](docs/UPDATES.md))
- **언어**: 다시 빌드하지 않고 나만의 언어를 추가할 수 있습니다([locales/README.md](locales/README.md))

## 사용법

- 트레이 아이콘: **왼쪽 클릭**으로 새 메모, **오른쪽 클릭**으로 메뉴(손글씨, 투명 슬로건, 타이머도 여기에)
- 손글씨: 메모 오른쪽 위의 펜 또는 오른쪽 클릭의 '손글씨'. Esc/Enter로 끝내고 E로 지우개 전환
- 타이머: 스페이스로 시작/일시정지, R로 다시 시작. 오른쪽 클릭으로 스타일, 시간, 소리 변경
- 메모 위에서: 두 번 클릭해 편집, 오른쪽 클릭으로 메뉴, Delete로 삭제(트레이에서 되살릴 수 있음), Ctrl+L로 잠금
- 데이터는 `%APPDATA%\PinPin\`에 있으며 형식은 [docs/DATA.md](docs/DATA.md)를 참고하세요
